# Limitless Schools — Website Mockup (Draft)

A work-in-progress design mockup for the new **Limitless Schools** website — a New
Jersey state-approved DIR® school for children with autism, in Parsippany, NJ.

### ▶ How to view
- **Live:** open the GitHub Pages link for this repo, or
- **Offline:** download and open `index.html` in any browser (needs internet for photos/fonts).

### Notes for reviewers
- This is a **draft for review.** Some content is placeholder (e.g. testimonials,
  a few photos) and the forms are **demo-only** — not connected yet.
- Built as a simple static site (HTML/CSS/JS). Photos are the school's own.
- Designed accessible-first: calm palette, keyboard-friendly menus, respects
  "reduce motion," labeled forms.
